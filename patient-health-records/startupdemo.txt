Terminal 1 — Ganache + contract
First check if Ganache is already running:
Test-NetConnection 127.0.0.1 -Port 8545
If it shows TcpTestSucceeded : True, Ganache is already running. Leave it alone and continue to Terminal 2.
If it shows False, start a fresh local chain:
cd C:\Users\srira\Desktop\FYP\FYP\patient-health-records\backend
npm.cmd run blockchain:ganache
Keep that terminal open. Then open another terminal and deploy the contract:
cd C:\Users\srira\Desktop\FYP\FYP\patient-health-records\backend
npm.cmd run blockchain:deploy
Because the setup uses deterministic Ganache, the contract deploys to the configured local address.
Terminal 2 — Database migration + backend
cd C:\Users\srira\Desktop\FYP\FYP\patient-health-records\backend

npm.cmd run dev

http://localhost:5000/api/health
