STEP 1: UPDATE BACKEND URL (CRITICAL!)
================================================================================

1. Find your computer's IP address:
   
   Open PowerShell and run:
   > ipconfig
   
   Look for "IPv4 Address" (e.g., 192.168.1.100)

2. Edit this file:
   patient-health-records/patient_app/lib/providers/auth_provider.dart

3. On line 15, change:
   static const String baseUrl = 'http://10.0.2.2:5000/api';
   
   To (replace with YOUR IP):
   static const String baseUrl = 'http://192.168.1.100:5000/api';

4. IMPORTANT: Your phone and computer must be on the same Wi-Fi network!

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Network Error" in app
Solution: 
  - Check backend is running
  - Verify IP address in auth_provider.dart
  - Both devices on same Wi-Fi
  - Allow port 5000 in firewall

Problem: Device not authorized
Solution:
  - Check phone for USB debugging prompt
  - Tap "Always allow"
  - Run: adb kill-server && adb devices

Problem: Build stuck/taking forever
Solution:
  - First build is slow (10 min) - be patient!
  - If truly stuck after 15 min, press Ctrl+C and retry
  - Run: flutter clean && flutter pub get
